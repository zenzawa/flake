# Steam
In Steam, open a game’s Properties → Launch Options and set:
`nvidia-offload %command%`

with mangohud:

`MANGOHUD_CONFIG=fps,gpu_name,gpu_stats mangohud nvidia-offload %command%`

## toggle mangohud

`Right Shift + F12`
